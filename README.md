## 🌟 Key Features

- **📱 Fully Mobile Responsive:** Designed for seamless viewing across phones, tablets, and desktop browsers.
- **🐶 Adoptable Dog Catalog:** Showcases available rescue dogs with high-resolution photos, age, breed info, and personality tags.
- **📝 Interactive Application Portal:**
  - Dynamic toggle between **Adoption** and **Foster** forms.
  - Auto-selects specific dogs when visitors tap **"Apply for [Dog Name]"**.
  - Interactive popup modal confirming successful application submission.
- **📊 Impact Counter:** Highlights key metrics like total rescues, completed adoptions, and healthcare stats.

## 🛠️ Built With
